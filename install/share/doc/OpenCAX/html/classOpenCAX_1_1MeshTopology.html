Detailed Description

网格拓扑关系构建器

MeshTopology 根据 Mesh 中的 nodes / cells 自动构建拓扑关系。

当前支持：

  • edge2node : edges()
  • cell2edge
  • edge2cell
  • node2edge
  • node2cell
  • node2node
  • cell2cell
  • boundary_edges
  • boundary_nodes
  • boundary_cells

后续三维面拓扑可继续扩展：

  • faces
  • cell2face
  • face2cell
  • node2face
