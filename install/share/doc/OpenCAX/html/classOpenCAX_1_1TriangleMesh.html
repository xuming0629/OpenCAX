Detailed Description

二维三角形网格

TriangleMesh 是 OpenCAX 中用于表示二维三角形网格的专用网格类。

设计说明：

  • 继承自 Mesh
  • 节点仍然使用 MeshNode{x, y, z}
  • 对于二维平面网格，z = 0.0
  • 单元类型固定为 CellType::Triangle3

支持：

  • 手动添加节点与三角形
  • 结构化矩形三角剖分
  • 非结构三角形网格
  • 三角形面积计算
  • 三角形重心计算
  • 边提取
  • 边界边提取
  • 边界节点提取

后续可直接对接：

  • Gmsh 2D 三角网格
  • FEM P1/P2 三角形单元
  • VTK 可视化
