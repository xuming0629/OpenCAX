Detailed Description

二维三角形网格类

TriangleMesh 继承自 Mesh，用于保存和处理 Triangle3 网格。

支持：

  • 结构矩形区域三角网格生成
  • 非结构三角网格构造
  • 单元面积计算
  • 总面积计算
  • 单元质心计算
  • 包围盒计算
  • 三角形网格合法性检查

检查三角形网格是否合法
