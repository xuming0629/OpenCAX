Detailed Description

通用网格基础容器

Mesh 是 OpenCAX 网格模块的基础数据结构， 用于保存网格节点、网格单元以及网格元信息。

Mesh 本身只负责基础数据存储，不负责复杂拓扑关系。

复杂拓扑关系，例如：

  • edge2node
  • cell2edge
  • edge2cell
  • node2cell
  • node2node
  • cell2cell
  • face2cell

应由 MeshTopology 构建。
