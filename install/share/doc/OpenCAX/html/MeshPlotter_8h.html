Detailed Description

OpenCAX 网格绘图工具类声明

MeshPlotter 属于 OpenCAX Post/Plot 模块。

该类通过 C++ 调用 Python matplotlib 脚本，实现类似 FEALPy / iFEM 的网格显示能力。

支持：

  • show_mesh : 显示完整网格
  • find_node : 查找并高亮指定节点
  • find_edge : 查找并高亮指定边
  • find_face : 查找并高亮指定面
  • find_cell : 查找并高亮指定单元

支持网格类型：

  • 2D 三角形网格
  • 2D 四边形网格
  • 3D 四面体网格
  • 3D 六面体网格

后续可扩展：

  • Prism6 / Prism15
  • Pyramid5 / Pyramid13
  • 混合网格
