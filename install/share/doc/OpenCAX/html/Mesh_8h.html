Detailed Description

OpenCAX 通用网格基础容器声明

Mesh 是 OpenCAX 网格模块的基础数据结构。

它负责保存：

  • 网格基础信息 MeshInfo
  • 网格节点 MeshNode
  • 网格单元 MeshCell

Mesh 本身只负责基础数据存储，不负责复杂拓扑关系。

复杂拓扑关系，例如：

  • edge2node
  • face2node
  • cell2edge
  • cell2face
  • edge2cell
  • face2cell
  • node2cell
  • node2node
  • cell2cell

应由 MeshTopology 构建。
