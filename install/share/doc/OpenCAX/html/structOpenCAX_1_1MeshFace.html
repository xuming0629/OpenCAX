Detailed Description

网格面

MeshFace 表示三维体网格中的一个拓扑面。

MeshFace 通常由 MeshTopology 构建，用于描述：

  • face2node : 面到节点
  • face2cell : 面到相邻单元
  • cell2face : 单元到面

示例：

Tetra4 的面通常是 Triangle3。

type = CellType::Triangle3;
node_ids = {0, 1, 2};
cell_ids = {0};

Note
MeshFace 是拓扑层结构，主要用于全局邻接关系和边界识别。 对于 FEM 中需要面的局部方向、法向、Jacobian 等信息的场景， 应由具体 FEMElement 或 CellTopology 的扩展接口处理。
