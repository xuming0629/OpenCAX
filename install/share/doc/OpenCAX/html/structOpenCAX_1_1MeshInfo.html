Detailed Description

网格基础信息

网格信息

MeshInfo 保存网格级别的元信息。

包括：

  • name : 网格名称
  • source : 网格来源，例如 Gmsh、TetGen、Structured、Imported
  • unit : 网格单位
  • dimension : 网格拓扑维度

保存整个 Mesh 的描述信息。
