class  OpenCAX::TriangleMeshRefiner
 

Detailed Description

OpenCAX 三角形网格加密工具

当前支持：

  • 一致加密 / uniform refinement
  • 最长边二分加密 / longest-edge bisection refinement
  • 指定单元局部二分加密

设计说明：

  1. TriangleMeshRefiner 不修改原始网格，而是返回一个新 TriangleMesh。
  2. 所有新节点使用边中点。
  3. 共享边只创建一个中点，保证拓扑一致。
  4. 局部二分时，如果邻居共享被切分边，也会同步切分，避免悬挂点。
